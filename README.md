# 📚 Інформатика — Навігатор матеріалів

Веб-застосунок для швидкого доступу учнів до навчальних матеріалів з інформатики та інтерактивних ігор-тренажерів.

## Опис

Сайт містить кнопки для кожного класу, які ведуть на відповідні папки з матеріалами на Google Диску (захищені кодами доступу), а також ігри для тренування навичок роботи з мишкою та клавіатурою. Призначений для використання як стартова сторінка на комп'ютерах у кабінеті інформатики.

Коди доступу зберігаються в Google Таблиці та можуть змінюватися без оновлення сайту.

## Сторінки

- **Головна** (`index.html`) — вибір класу для доступу до матеріалів
- **Правила** (`rules.html`) — правила поведінки в кабінеті інформатики
- **Ігри** (`games.html`) — каталог ігор-тренажерів та завантаження інсталятора гри «Сходинки до інформатики»

## Ігри-тренажери

### 🎈 Лопни кульку (`games/mouse-click/`)
Тренування швидкості та точності кліків мишкою.
- 3 рівні складності
- Типи кульок: звичайні, золоті, бомби, бонус часу
- 60 секунд на раунд, 3 життя

### 🔤 Знайди літеру (`games/keyboard-letters/`)
Тренування роботи з клавіатурою (українська розкладка).
- 5 рівнів складності (від початківця до експерта)
- Літери: а-я, А-Я, цифри, символи
- Система комбо (серій правильних натискань)
- Таймер для кожної літери

### ⌨️ Набери слово (`games/keyboard-typing/`)
Тренування швидкості набору цілих слів.
- 3 рівні складності:
  - Легкий: слова 3-5 літер, 12 сек на слово, 1 слово
  - Середній: слова 4-7 літер, 10 сек на слово, до 2 слів
  - Важкий: слова 5-10 літер, 9 сек на слово, до 2 слів
- Типи слів: звичайні (×1), золоті (×2), швидкі (×1.5), бонус часу (+5с)
- ~340 українських слів у словнику
- Система комбо та статистика (точність, швидкість)

### 🎯 Влучний стрілець (`games/mouse-aim/`)
Тренування точності кліків по мішенях.
- 3 рівні складності (різний розмір та швидкість мішеней)
- Зони влучання: зовнішня, середня, центр (різні очки)
- Типи мішеней: звичайні, золоті, швидкі, бонус часу
- Система комбо за серії влучань

### 🃏 Знайди пару (`games/memory-pairs/`)
Класична гра на пам'ять з картками.
- 3 рівні складності (3×4, 4×4, 4×5)
- Теми карток: тварини, їжа, транспорт (емодзі)
- 3D анімація перевертання карток
- Система комбо та бонус за швидкість

### 🧩 Перетягни предмет (`games/mouse-drag/`)
Гра на сортування предметів перетягуванням.
- 3 рівні складності з різними темами:
  - Легкий: Фрукти та Овочі (2 категорії, 8 предметів, 80с) — пул: 16+16
  - Середній: Тварини за середовищем (3 категорії, 12 предметів, 100с) — пул: 13+17+17
  - Важкий: Пори року (4 категорії, 16 предметів, 120с) — пул: 12+11+11+12
- Підтримка сенсорних екранів
- Система комбо за серії правильних відповідей
- Бонус часу за швидке завершення

## Використання

1. Відкрийте `index.html` у браузері
2. Натисніть кнопку свого класу
3. Введіть код доступу для вашого класу
4. Після успішної перевірки — перехід до матеріалів на Google Диску
5. Або натисніть "Ігри-тренажери" для тренування навичок
6. Або натисніть "Правила поведінки в кабінеті" для перегляду правил

## Технології

- HTML5
- CSS3 (зовнішній файл `styles.css`)
- JavaScript (vanilla, тільки для ігор)
- Google Fonts (Balsamiq Sans, Nunito, Inter)

## Особливості

- Анімований фон з ефектом матриці та плаваючими фігурами
- Градієнтні кнопки з ефектами при наведенні
- Захист матеріалів кодами доступу (зберігаються в Google Таблиці)
- Анімація «кольорова шторка» з папкою при успішному вході
- Адаптивний дизайн (мобільна версія < 500px)
- Підтримка `prefers-reduced-motion` для доступності
- Збереження рекордів ігор у localStorage
